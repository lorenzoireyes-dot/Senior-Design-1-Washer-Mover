# Preliminary Design Failure Mode and Effects Analysis

The Milestone 03 safety section evaluates potential failure modes in the washer positioning system. Probability grades A through E and severity grades I through IV are screening judgments rather than measured frequencies.

| Component or hazard | Failure scenario | Initial risk index |
| --- | --- | --- |
| Electromagnet and washer | Unexpected movement or release | II C |
| Motor and moving arm | Excessive speed | III C |
| Arch and mounted devices | Loose support or mount | III D |
| Electrical wiring | Exposed or obstructive wiring | II C |
| User interface | Unclear operating state | III C |
| Motion control | Incorrect command or lost feedback | II D |

### Reported mitigations

- Solenoid restraint for unintended washer release.
- Motion speed limitation.
- Rigid arch supporting mounted components.
- Wiring routed away from user contact.
- LED state indicators for start and stop.

These safeguards are documented as implemented in the report, but **final safety verification was not established**. The remaining checks include washer retention, stop response, stability, cable inspection, and failure handling.
