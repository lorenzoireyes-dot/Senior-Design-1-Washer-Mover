# Simulink Motor Control Models

The controller receives a target position from the MATLAB GUI and communicates motor commands to an Arduino Mega with an L298N driver. Milestone 03 tested proportional and derivative response with a sinusoidal angular reference.

Reported experimental gains: **P = 0.7, I = 0, D = 0.05**.

**Source status:** The native `.slx` model and data logs were not included with the submitted report. No executable model is claimed.
