# MATLAB Application and Vision Code

Milestone 03 includes the native MATLAB App Designer application:

- [select_gui_test.mlapp](select_gui_test.mlapp)

According to the team report, the GUI coordinates webcam initialization, background and current image capture, image subtraction, washer detection and identification, `gameState` storage, target selection, and commands to a Simulink motor control workflow.

The uploaded `.mlapp` is the application source. A separate `.m` script collection and standalone Simulink `.slx` model have not been verified in this directory. Executing the application may require appropriate MATLAB toolboxes and the original hardware configuration.
