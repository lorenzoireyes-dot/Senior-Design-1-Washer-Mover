# MATLAB Application and Vision Code

Milestone 03 includes the native MATLAB App Designer application:

- [select_gui_test.mlapp](select_gui_test.mlapp): MATLAB App Designer GUI
- [MotorModel_Sp23_V22b.slx](MotorModel_Sp23_V22b.slx): Simulink motor control model

According to the team report, the GUI coordinates webcam initialization, background and current image capture, image subtraction, washer detection and identification, `gameState` storage, target selection, and commands to a Simulink motor control workflow.

Both the `.mlapp` application and `.slx` model are present. A separate `.m` script collection has not been verified in this directory. Running the system requires compatible MATLAB and Simulink installations, relevant dependencies, and the original hardware setup; successful execution has not been independently tested.
